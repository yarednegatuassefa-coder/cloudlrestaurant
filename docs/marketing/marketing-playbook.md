# Cloud L Marketing Playbook
Goal: improve local discovery and turn menu browsing into accurate order requests while preserving staff confirmation.

## Audience / positioning
Nearby residents, workers, visitors, groups, and households choosing pickup, delivery, or dine-in. Working position: convenient way to explore Cloud L's menu and submit an order request with clear service options.

## Message pillars
Accurate menu/availability; simple request steps; genuine local relevance; trust through staff confirmation. Verify menu, ETB prices, hours, delivery zones/fees, and availability before publishing.

## Channels / funnel
Verified local profile if eligible → menu/food content → mobile-first menu and clear CTA → service mode → request → staff confirms availability/final amount → confirmed order/payment workflow. Request submission is not confirmed order/payment. Use real menu highlights and verified featured items. Retention messages must be opt-in and human-approved.

## Measurement / review
Separate menu views, item selection, request starts/completions, staff-confirmed orders, cancellations, and repeat orders. Aggregate only; protect contact details, directions, private tracking links, and payment data. Staff verifies all menu, price, availability, hours, fee, and offer facts. No fake reviews, bulk messages, ads, publication, or order/payment changes without approval.
